# bac-website

Bay Area Chess full-stack website (React client + Express API).

## Structure

```
server/api/          Express API, controllers, routes
client/              React app (Vite), components, pages, SCSS
```

## Development

```bash
npm run install:all
npm run dev:api    # API on :5001
npm run dev:client # React on :3000
```

Open http://localhost:3000 (or your machine's LAN IP on port 3000 from another device).
